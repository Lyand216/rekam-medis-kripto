05 — Tentang

        
Tentang Sistem

        
Rekam medis adalah data paling sensitif di fasilitas kesehatan. Sistem ini berlapis mengamankannya.

      


      

        

          
Lapisan Kriptografi

          
    
            
  1. Vigenere Cipher — substitusi polialfabetik dengan kunci berulang. Huruf non-alfabet dibiarkan agar struktur data tetap utuh. Ini penyamaran awal, bukan pengaman tunggal.
    2. 
            
  2. AES-256-GCM — enkripsi simetris berkecepatan tinggi dengan autentikasi (AEAD). Perubahan 1 bit pada ciphertext akan terdeteksi.
    3. 
            
  3. RSA-2048-OAEP — membungkus kunci sesi AES sehingga hanya pemegang kunci privat yang bisa membukanya. Pola key encapsulation.
    4. 
          

          
VIGENERE + AES-256-GCM + RSA-2048-OAEP

        


        

          
Alur Kerja

          
Plaintext (rekam medis)
      │
      ▼  Vigenere(key)
Teks tersamarkan
      │
      ▼  AES-256-GCM(keySesi, iv)
      │        └── keySesi dibungkus RSA-OAEP(pubKey) → wrappedKey
      ▼
Payload { iv, wrappedKey, ciphertext }

          
Dekripsi berjalan terbalik: RSA buka kunci → AES buka data → Vigenere buka teks.

        

      


      

        
Catatan Penting

        
    
          
  • Web demo ini berjalan 100% di sisi klien (Web Crypto API) — tidak ada data yang dikirim ke server.
    • 
          
  • Semua kunci hanya ada di memori browser; menutup tab akan menghapusnya kecuali Anda menyimpan kunci privat.
    • 
          
  • Vigenere adalah kriptografi klasik yang mudah dipatahkan dengan analisis frekuensi; nilainya di sini adalah lapisan tambahan, bukan pengganti AES/RSA.
    • 
          
  • Untuk produksi: gunakan penyimpanan kunci (HSM / Key Vault), audit trail, kendali akses berbasis peran, dan kepatuhan regulasi rekam medis elektronik.
    • 
          
  • Jika kunci privat hilang, data tidak dapat dipulihkan.
